# 🛑 Агент AI Job Seeker — Чекпоинт сохранения сессии

**Текущий статус проекта:**
Мы успешно разработали логику для коммерческого распространения программы (AI Job Seeker Agent). Приложение теперь включает систему авторизации и динамический интерфейс.

## 📌 Что уже сделано (Текущий прогресс):
1. **Система Авторизации:** 
   - Написано окно `LoginWindow` в `AIJobSeekerApp.py`, которое появляется до основного приложения.
   - Авторизация сверяет данные с файлом `Data/users.json`. (Доступ дается только после совпадения логина и пароля).
2. **Мультиязычный UI (для логина):** 
   - В окне логина добавлен переключатель языков (EN, UK, RU, PL). Язык меняется в реальном времени.
3. **Функция "Запомнить меня":**
   - Учетные данные сохраняются в `Data/saved_login.json` для автовхода.
4. **FAQ и Инструкции:**
   - Добавлена синяя кнопка "❓ FAQ" в главном меню, которая вызывает локальный файл `FAQ.md` на английском языке.
5. **Генератор Резюме (CV):**
   - Внедрены 4 разных дизайна CV (Modern, Minimalist, Creative, IT Tech), которые выбираются случайно.
   - Пофикшен баг с дефисами в маркированных списках через промпт LLM и `lstrip` в Python.

## 🚀 Что нужно сделать следующим шагом (План после перезагрузки):
- Реализовать парсинг **пользовательского HTML-шаблона резюме (из Canva)**. 
- Логика: скрипт берет кастомный HTML-файл пользователя, находит в нем плейсхолдеры (например, `{{EXPERIENCE}}`, `{{SKILLS}}`), заменяет их на текст, сгенерированный LLM, и сохраняет в идеальный PDF с помощью Playwright без нарушения верстки.
