🚀 AI Job Seeker Agent

Полная инструкция по использованию бота-рекрутера

1. Как это работает?

Наш ИИ-агент полностью автоматизирует процесс поиска работы. Он делает следующее:

  • Парсит вакансии с популярных сайтов (Pracuj.pl, JustJoin.it, Djinni и международных досок).
  • Анализирует описание вакансии с помощью локального LLM (Ollama) и выставляет процент совпадения (Match %).
  • Генерирует уникальное резюме (PDF) под конкретную компанию, выделяя нужные навыки.
  • Сам заполняет формы, отвечает на кастомные вопросы ATS-систем (например, Traffit), ставит галочки RODO и нажимает "Отправить".

2. Настройки в программе

Выбор формата резюме (CV Template)

Вы можете выбрать один из дизайнов для генерируемого резюме:

  • Classic_ATS - Строгий формат, который идеально читается ATS ботами корпораций.
  • Modern_Tech - Современный, с выделенной боковой панелью. Отлично для IT-компаний.
  • Creative_Startup - Яркий и стильный. Для стартапов.

Режимы работы

  • Non-Tech Job - Отключает глубокий LLM-анализ вакансий. Бот спамит откликами на всё подряд.
  • Ignore Large Companies - Пропускает гигантские корпорации (Google, Amazon), где боты бессильны против бюрократии (Taleo/Workday).
  • Autonomous Mode - Бот будет работать бесконечно, просыпаясь каждые 30 минут для поиска новых вакансий.

3. Решение проблем (Bulletproof Engine)

Бот оснащен системой Bulletproof Engine. Если он натыкается на сложную кастомную форму, он самостоятельно собирает контекст вопросов и отправляет их в LLM для анализа. Если он окончательно не справляется, вакансия помечается как "Failed".

Все результаты (как успешные отклики, так и отказы с причинами) записываются в Dashboard.

🚀 AI Job Seeker Agent

Complete guide on using the automated recruiter bot

1. How it works?

Our AI agent fully automates the job search process:

  • Scrapes job boards (Pracuj.pl, JustJoin.it, Djinni, international boards).
  • Analyzes job descriptions using local LLM (Ollama) and scores match percentages.
  • Generates a unique PDF CV tailored to the specific company.
  • Autofills application forms, answers custom ATS questions, ticks RODO checkboxes, and hits "Apply".

2. Application Settings

CV Templates

  • Classic_ATS - Clean format, 100% readable by corporate ATS bots.
  • Modern_Tech - Modern sidebar layout for IT companies.
  • Creative_Startup - Vibrant and stylish for startups.

Work Modes

  • Non-Tech Job - Disables deep LLM analysis. Spams applications strictly by keywords.
  • Ignore Large Companies - Skips FAANG and massive banks where bots fail against Workday/Taleo.
  • Autonomous Mode - Bot runs indefinitely, waking up every 30 minutes to search for new jobs.

3. Troubleshooting (Bulletproof Engine)

The bot is equipped with a Bulletproof Engine. If it encounters a complex custom ATS form, it parses the questions and sends them to the local LLM for context-aware answering.

All application results are logged in your Dashboard.
